# 3x-ui 2.9.4+25 — изменения в разрабатываемой ветке

Эта ветка продолжает 3x-ui 2.x для пользователей, которые не хотят переходить
на 3.x, но хотят применять новые выпуски Xray-core. Последний опубликованный
Docker-образ по-прежнему `ghcr.io/lagnuty/3x-ui:2.9.4-24`; тег `2.9.4-25`
нельзя использовать, пока сборка и публикация не завершены.

Целевая версия ядра: **Xray v26.10.17** (на момент подготовки — pre-release).
Текущая версия панели в исходном коде: **2.9.4+25**.

## Что изменилось в интерфейсе

- В редакторе outbound → TLS появился `Use system CAs`. Он управляет
  `streamSettings.tlsSettings.useSystemCA`: выключен — поле отсутствует и Xray
  использует встроенные корневые сертификаты; включен — `true` и применяется
  системное хранилище сертификатов. Это не эквивалент `allowInsecure`.
- В редакторах inbound/outbound → FinalMask → UDP → XDNS поле `Domains` теперь
  принимает несколько имён в `domains[].names`. Для каждого доменного набора
  доступны прежние `lenLimit` (1–255), `labelLimit` (1–63), DNS types и EDNS0.
- Поле `Resolvers` теперь принимает список адресов `resolvers[].addrs`:
  обычный `host:port` (UDP), `tcp://host:port` или DoH URL `https://…`.
  `Resolver workers` записывается как `worker`; пустое/нулевое значение
  оставляет ядру default 32. Переключатель `Resolver TLS` открывает поля
  `serverName`, SHA256 pin и `useSystemCA` в `tlsConfig`.
- Матрица обновления Xray показывает контрольные точки v26.10.10 и v26.10.17.
  Предупреждение по gRPC различает версии до исправления peer-restart reconnect
  и v26.10.17, где эта ошибка исправлена. Сам транспорт остаётся deprecated.

Старые XDNS-поля `name`, `type`, `settings.addr` мигрируют при загрузке
сохранённых stream settings; новые конфигурации используют `names` и `addrs`.
Точный JSON, ограничения и defaults описаны в
[техническом справочнике](XRAY_26_UI_FIELDS_RU.md).

## Проверки и ограничения

- Обновлённый совместимый JSON прошёл `xray run -test` на официальном бинарнике
  Xray v26.10.17. Проверены синтаксис JS-моделей и преобразование XDNS JSON.
- Полная Go-сборка и Docker multi-arch сборка пока не выполнены; этот документ
  не утверждает, что образ `2.9.4-25` уже опубликован.
- XDRIVE, MASQUE и редактор файловых Lua-скриптов пока не добавлены. Их не
  следует считать поддерживаемыми полями интерфейса или share links.
